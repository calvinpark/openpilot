TSK Manager
UDS Sweep
Run this with the car in Not Ready to Drive (powered on, engine/hybrid not started). It sends every UDS service byte 0x00–0xFF and every sub-function of the ones that answer — including operations that can reset the EPS or silence it on the bus. Both are recovered by a power cycle, and the probe restores fault logging and CAN output after every block.

It runs for 5 minutes and stops. Results are written to the device as they arrive, so nothing is lost if the 12V sags — just run it again and it resumes exactly where it stopped.
