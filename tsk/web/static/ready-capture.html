READY Capture
Run this with the car in READY (hybrid system started, foot on the brake, in Park). Run the UDS Sweep in Not Ready to Drive first — this pass re-tests what that one found, so it is much more useful second.

It records every CAN frame with its full payload for 90 seconds, then re-asks only requests the first sweep already characterised. No unknown bytes are sent while the car is drivable. About 5 minutes total.
